
hod 0.0.1 — Hodstack makes coding agents more productive.

USAGE
  hod <skill> <prompt>
  hod <command> [options]

COMMANDS
  init         Write the files that a coding agent reads in this directory
  list         List the installed skills
  update       Install the newest build of hod and write the project files
  completions  Print a shell completion script

OPTIONS
  -h, --help     Print help
  -V, --version  Print version
