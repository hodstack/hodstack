# hod

`hod` is the Hodstack command line program. Hodstack makes coding agents more productive.

```sh
cargo install hod
```

Write the two files that a coding agent reads:

```sh
hod init
```

Hodstack is before its first tag. For the other ways to install it, and for the skills that it runs, see [github.com/hodstack/hodstack](https://github.com/hodstack/hodstack).
