# Hodstack logo

The Hodstack logo is the word `hodstack` set in JetBrains Mono Bold, with a three-bar underline. The bars alone form the icon: a stack.

All text is outlined to paths, so every file renders the same everywhere, with no font installed.

## Files

| Folder | Contents |
| --- | --- |
| `wordmark/` | The wordmark on a transparent background. Color for light backgrounds, inverse for dark, black and white for single-color print. |
| `lockup/` | Icon and wordmark together, horizontal and stacked, each with an inverse. |
| `badge/` | The wordmark on a rounded card, light and dark. |
| `icon/` | The stack mark alone. Color, black and white. |
| `app-icon/` | The stack mark on a rounded square tile, dark and light. |
| `favicon/` | The stack mark drawn for a 32 px grid. |
| `social/` | A 1280×640 banner for social cards and repository previews. |
| `png/` | PNG exports of the files above. Transparent where the source is transparent. |

## Use

Pick the variant made for your background: color on light, inverse on dark. Keep clear space around the logo equal to the height of one underline bar. Do not recolor, stretch, or reset the wordmark in another font.
